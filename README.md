# TechNova - Landing Page Design

An elegant, user-centric, and fully responsive landing page designed for **TechNova**—an ecosystem engineered for tech enthusiasts to upscale their skills, collaborate on high-tier projects, find job listings, and monetize their experience.

## Live Demo
🔗 **[View Live Site](https://github.io)**

---

## 🚀 Key Features Built-In

- **Dynamic Hero Section:** Highly engaging headings with structured calls-to-action (`Join as Learner` and `Post a Project`).
- **Interactive "How It Works" Flow:** Clean, grid-based breakdown displaying the user lifecycle: *Learn*, *Collaborate*, *Earn*, and *Grow*.
- **Value Propositions Grid ("Why Join Us"):** Comprehensive cards displaying system benefits such as:
  - Live Learning Sessions
  - Verified Job Posts
  - Co-Founder Support
  - Instant Onboarding
  - Quality Tech Services
  - Community Mentorship
- **Responsive Navigation:** Accessible layout containing core action paths (`Home`, `Learn`, `Post a Job`, `About`, `Login / Sign Up`) alongside a standout `Join Now` anchor button.

---

## 🛠️ Technology Stack Breakdown

As indicated by the repository's linguistic structure, this layout relies purely on front-end optimization without bloating frameworks:

- **HTML5 (69.1%):** Provides a semantic structural foundation for layout components and modern web elements.
- **CSS3 (24.7%):** Incorporates clean styling layouts, unique brand-specific palettes (including TechNova's distinct emerald teal tones), shadows, card styling, and grid alignments.
- **JavaScript (6.2%):** Manages simple logic layers such as mobile navigation toggles (hamburger menu activations) and view triggers.

## ⚙️ How to Run Locally

If you want to pull down this code and experiment with changes locally on your machine, follow these instructions:

### 1. Clone the Project
```bash
git clone https://github.com
cd Landing-page-design
```

### 2. Launch the Application
- **Direct execution:** Simply double-click the `index.html` file in your system folder to view the layout directly inside any default browser window.
- **Live Server Expansion:** If using Visual Studio Code, right-click `index.html` and select **Open with Live Server** to enable real-time style reloading as you update the code scripts.
